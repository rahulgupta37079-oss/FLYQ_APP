# FLYQ Play Store Submission - Final Checklist

## 📸 **SCREENSHOT REQUIREMENTS**

### **What You Need to Capture:**

**Minimum Required**: 2 screenshots  
**Recommended**: 6-8 screenshots  
**Format**: PNG or JPEG (24-bit)  
**Size**: 
- Portrait: 1080 x 1920 pixels (or 9:16 ratio)
- Landscape: 1920 x 1080 pixels (or 16:9 ratio)

### **Recommended Screenshots to Capture:**

1. ✅ **Home Screen** (portrait)
   - Shows app name, version, menu

2. ✅ **WiFi Connection** (portrait)
   - Network scanner, drone networks

3. ✅ **Control Screen** (portrait)
   - Joysticks, telemetry, ARM button

4. ✅ **Control Screen** (landscape)
   - Shows optimized landscape layout

5. ✅ **Settings Screen** (portrait)
   - Settings, support, contact info

6. ✅ **Camera Screen** (portrait)
   - Camera preview UI

### **How to Capture Screenshots:**

**On Android Device:**
- Press **Power + Volume Down** simultaneously
- Screenshots saved to Gallery/Screenshots folder

**Tips for Professional Screenshots:**
- Ensure good battery level (>70%)
- Clean status bar (good signal, WiFi)
- Use device time around 10:00 or 2:00
- Capture in good lighting
- Make sure UI elements are visible
- No personal data visible

## 📋 **PLAY STORE SUBMISSION PROCESS**

### **Step 1: Create App in Console**
1. Go to https://play.google.com/console
2. Click "Create app"
3. Fill in:
   - App name: **FLYQ Drone Controller**
   - Default language: **English (United States)**
   - App or game: **App**
   - Free or paid: **Free**
4. Accept declarations and create

### **Step 2: Set Up Main Store Listing**
1. Go to "Store presence" → "Main store listing"
2. Fill in:
   - **App name**: FLYQ Drone Controller
   - **Short description** (80 chars):
     ```
     Professional drone controller for LiteWing ESP32-S3. Control, monitor, and fly.
     ```
   - **Full description** (from PLAY_STORE_MATERIALS.md - I'll provide)
   - **App icon**: Upload icon.png (512x512)
   - **Feature graphic**: Upload (1024x500) - I have 3 variations ready
   - **Phone screenshots**: Upload your 6-8 screenshots
   - **Category**: Productivity
   - **Contact email**: info@passion3dworld.com
   - **Privacy policy URL**: (need to host PRIVACY_POLICY.md)

### **Step 3: Configure App Access**
- Select: "All functionality is available without special access"
- Or add test account if needed

### **Step 4: Ads Declaration**
- Select: "No, my app does not contain ads"

### **Step 5: Content Rating**
1. Click "Start questionnaire"
2. Answer all "No" (no violence, no sexual content, etc.)
3. Result: **Everyone** rating
4. Save

### **Step 6: Target Audience & Content**
- Select age groups: **All ages**
- News app: **No**
- COVID-19: **No**
- Data safety: Fill out (app collects no data)

### **Step 7: Upload App Bundle**
1. Go to "Release" → "Production"
2. Click "Create new release"
3. Upload your **.aab file** (from EAS build)
4. Add release notes:
   ```
   Version 2.1.0 - Professional Edition
   
   • Professional drone controller for LiteWing ESP32-S3
   • Dual joystick flight controls
   • Real-time telemetry monitoring
   • Full landscape/portrait support
   • ARM/DISARM safety system
   • Emergency stop functionality
   • WiFi connectivity management
   • 24/7 support access
   ```
5. Save and review

### **Step 8: Submit for Review**
1. Review all sections (must all be ✅)
2. Click "Send for review"
3. Wait for approval (1-7 days)
