           📱 FLYQ APP - SIMPLE INSTALL GUIDE 📱
════════════════════════════════════════════════════════════════

🎯 GOAL: Install FLYQ Drone Controller app on your Android phone

⏱️ TIME: 5-10 minutes

════════════════════════════════════════════════════════════════
          METHOD 1: WHATSAPP (EASIEST - RECOMMENDED)
════════════════════════════════════════════════════════════════

STEP 1: Build APK on Your PC
────────────────────────────────────────────────────────────────
1. Open CMD (Command Prompt)
2. Type these commands:

   cd C:\Users\PROFESSORHULK\FLYQ_APP\android
   gradlew assembleDebug

3. Wait 3-5 minutes for build to complete

STEP 2: Find Your APK File
────────────────────────────────────────────────────────────────
Location: C:\Users\PROFESSORHULK\FLYQ_APP\android\app\build\outputs\apk\debug\app-debug.apk

File size: ~30 MB

STEP 3: Send APK via WhatsApp
────────────────────────────────────────────────────────────────
1. Open WhatsApp on PC (web.whatsapp.com or desktop app)
2. Send "app-debug.apk" file to yourself or any contact
3. Open WhatsApp on your phone
4. Download the APK file (tap on it)

STEP 4: Install on Phone
────────────────────────────────────────────────────────────────
1. Tap the downloaded APK file
2. You'll see: "For your security, your phone is not allowed..."
3. Tap "Settings"
4. Enable "Allow from this source"
5. Tap Back button
6. Tap "Install"
7. Wait ~10 seconds
8. Tap "Open"

STEP 5: Grant Permissions
────────────────────────────────────────────────────────────────
When FLYQ app asks for permissions:
✅ Location - ALLOW (required for WiFi scanning)
✅ Storage - ALLOW (if asked)

STEP 6: Test the App
────────────────────────────────────────────────────────────────
1. Open FLYQ app
2. Tap "WiFi Scan"
3. Tap "Scan for Drones"
4. See list of WiFi networks
5. Networks with "LiteWing", "FLYQ", "ESP32" show drone icon 🚁

✅ DONE! App is installed and ready to use!

════════════════════════════════════════════════════════════════
         METHOD 2: USB CABLE (FAST - FOR DEVELOPERS)
════════════════════════════════════════════════════════════════

STEP 1: Enable Developer Mode on Phone
────────────────────────────────────────────────────────────────
1. Settings → About Phone
2. Tap "Build Number" 7 times
3. You'll see "You are now a developer!"

STEP 2: Enable USB Debugging
────────────────────────────────────────────────────────────────
1. Settings → Developer Options
2. Enable "USB Debugging"
3. Connect phone to PC via USB cable
4. On phone popup: Tap "OK" to allow USB debugging

STEP 3: Build APK (if not already built)
────────────────────────────────────────────────────────────────
cd C:\Users\PROFESSORHULK\FLYQ_APP\android
gradlew assembleDebug

STEP 4: Install via ADB
────────────────────────────────────────────────────────────────
1. Open CMD
2. Type:
   
   cd C:\Users\PROFESSORHULK\FLYQ_APP\android\app\build\outputs\apk\debug
   adb install app-debug.apk

3. Wait ~10 seconds
4. You'll see "Success" message
5. Find FLYQ icon in app drawer on your phone

✅ DONE! App is installed!

════════════════════════════════════════════════════════════════
              METHOD 3: GOOGLE DRIVE (ALTERNATIVE)
════════════════════════════════════════════════════════════════

STEP 1: Upload APK to Google Drive
────────────────────────────────────────────────────────────────
1. Build APK (see Method 1, Step 1)
2. Go to drive.google.com
3. Click "New" → "File upload"
4. Select: C:\Users\PROFESSORHULK\FLYQ_APP\android\app\build\outputs\apk\debug\app-debug.apk
5. Wait for upload (~30 MB)

STEP 2: Download on Phone
────────────────────────────────────────────────────────────────
1. Open Google Drive app on phone
2. Find "app-debug.apk"
3. Tap on it
4. Tap "Download"
5. After download, tap the file

STEP 3: Install
────────────────────────────────────────────────────────────────
Follow Method 1, Step 4

                    🧪 HOW TO TEST THE APP
════════════════════════════════════════════════════════════════

WITHOUT REAL DRONE (Just Testing)

4. Open FLYQ app
5. Tap "WiFi Scan"

7. Tap "Connect to Drone"
8. Control screen opens
9. Test controls:
   - ARM button → Drone arms
   - TAKEOFF → Drone takes off
   - Joysticks → Control flight
   - LAND → Drone lands
   - DISARM → Motors stop

                    🐛 COMMON PROBLEMS
════════════════════════════════════════════════════════════════

Problem: "No Java compiler found" when building
Solution: Install Java JDK 17 from https://adoptium.net/
          See FIX_JAVA_ERROR.md for details

Problem: APK won't install on phone
Solution: Settings → Apps → FLYQ → Uninstall old version
          Then try installing again

Problem: WiFi scan shows no networks
Solution: Settings → Apps → FLYQ → Permissions → Location → Allow
          Also enable Location services in phone settings

Problem: Can't connect to drone
Solution: First connect to drone WiFi using phone's WiFi settings
          THEN open FLYQ app and try connecting

Problem: App crashes immediately
Solution: Settings → Apps → FLYQ → Storage → Clear Data
          Then open app again
