═════════════════════════════════════════════════════════════════
  📲 INSTALL APK ON YOUR PHONE
═════════════════════════════════════════════════════════════════

METHOD A: Via USB Cable
────────────────────────────────────────────────────────────────
1. Enable USB Debugging on phone:
   Settings → About Phone → Tap "Build Number" 7 times
   Settings → Developer Options → Enable "USB Debugging"

2. Connect phone via USB cable

3. Install APK:
   cd C:\Users\PROFESSORHULK\FLYQ_APP\android\app\build\outputs\apk\debug
   adb install app-debug.apk

METHOD B: Transfer APK File
────────────────────────────────────────────────────────────────
1. Copy app-debug.apk to phone via:
   - WhatsApp (send to yourself)
   - Google Drive
   - Email
   - USB cable (copy to Downloads folder)

2. On phone:
   - Enable "Install unknown apps" for your file manager
   - Tap the APK file
   - Tap "Install"

═════════════════════════════════════════════════════════════════
  ⚙️ PREREQUISITES (Install once)
═════════════════════════════════════════════════════════════════

1. ANDROID STUDIO
   Download: https://developer.android.com/studio
   Install: Android SDK Platform 34, Build-Tools, Platform-Tools

2. JAVA JDK 17
   Download: https://adoptium.net/
   Verify: java -version

3. SET ENVIRONMENT VARIABLES (PowerShell as Admin)
   
   # Set JAVA_HOME
   [System.Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot", "Machine")
   
   # Set ANDROID_HOME
   [System.Environment]::SetEnvironmentVariable("ANDROID_HOME", "$env:LOCALAPPDATA\Android\Sdk", "Machine")
   
   # Add to PATH
   $oldPath = [System.Environment]::GetEnvironmentVariable("Path", "Machine")
   $newPath = "$oldPath;$env:LOCALAPPDATA\Android\Sdk\platform-tools;$env:LOCALAPPDATA\Android\Sdk\tools"
   [System.Environment]::SetEnvironmentVariable("Path", $newPath, "Machine")
   
   ⚠️ Restart CMD/PowerShell after setting variables!

  🐛 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════

ERROR: gradlew: command not found
────────────────────────────────────────────────────────────────
SOLUTION: Navigate to android folder
cd C:\Users\PROFESSORHULK\FLYQ_APP\android

ERROR: JAVA_HOME not set
────────────────────────────────────────────────────────────────
SOLUTION: Check environment variables
echo %JAVA_HOME%
echo %ANDROID_HOME%

If empty, set them using PowerShell (see Prerequisites section)

ERROR: SDK location not found
────────────────────────────────────────────────────────────────
SOLUTION: Create android\local.properties file:
sdk.dir=C:\\Users\\PROFESSORHULK\\AppData\\Local\\Android\\Sdk

ERROR: Build is slow
────────────────────────────────────────────────────────────────
SOLUTION: Use Debug build instead of Release
gradlew assembleDebug    (faster)

ERROR: APK won't install
────────────────────────────────────────────────────────────────
SOLUTION: Uninstall old version first
adb uninstall com.flyq.dronecontroller
